PDF Information

See page count, metadata, and per-page dimensions without uploading the file.

What you'll see

QuickPDF reads the PDF's trailer, cross-reference table, and Info dictionary. That reveals the number of pages, the document title, author, subject, creator and producer strings, plus the creation and modification timestamps. Each page's width and height are reported in PDF points (72 points = 1 inch).

Encrypted PDFs are rejected before we attempt to read metadata, because the Info dictionary itself may be encrypted. Very large PDFs are parsed in the browser using pdf-lib, which loads the whole structure into memory — for files above ~100 MB we recommend using a desktop tool instead.
