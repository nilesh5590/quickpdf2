How QuickPDF works

QuickPDF is a collection of seven PDF utilities that run entirely inside your web browser. When you choose a file, it is read locally by JavaScript using the File API. All the work — parsing, merging, rendering, OCR — happens on your device. Nothing is transmitted to a server, because there is no server.

This matters for two reasons. First, privacy: sensitive documents like contracts, medical records, and IDs never leave your computer. Second, security: there is no database to breach, no log of what you uploaded, and no account to compromise.

QuickPDF is built on trusted open-source libraries. PDF parsing and manipulation use pdf-lib. PDF rendering and text extraction use pdfjs-dist from Mozilla. OCR uses Tesseract.js, the WebAssembly build of Google's Tesseract engine.

Known limits

Compression redraws each page as a JPEG rather than re-encoding the original content streams, so text in a compressed PDF is no longer selectable. OCR is English-only in this version. Very large PDFs (over roughly 100 MB) may exhaust a phone's available memory. Password-protected PDFs are rejected deliberately.

Frequently asked questions

Are my files uploaded anywhere?

No. All processing happens in your browser using JavaScript and WebAssembly. Open your browser's developer tools, switch to the Network tab, and use any tool — you will see no requests carrying your file's contents.

Is QuickPDF really free?

Yes, with no accounts, no watermark, and no file limits imposed by us. The only limits are what your browser can handle.

Can I use QuickPDF offline?

Yes. After your first visit, the application shell is cached by a service worker. OCR needs to download English language data on first use, after which it is cached too.

Which browsers are supported?

Any modern browser: Chrome, Edge, Safari, Firefox, and their mobile versions.
